Unidad 2 · Bloque B — Operaciones con expresiones algebraicas

Sumar, restar y multiplicar polinomios aplicando las propiedades básicas.

🔎 Las partes de un término

En un término como −3x² podemos reconocer dos partes que se multiplican:

Coeficiente: −3
Es la parte numérica. Incluye el signo: aquí el coeficiente es −3, no 3.
Parte literal: x²
Está formada por las variables con sus exponentes: aquí es x², no solamente x.

Sí son semejantes: 3x² y −5x², porque comparten la parte literal x². Sumamos sus coeficientes y conservamos esa parte:

3x² + (−5x²) = (3 − 5)x² = −2x².

No son semejantes: 3x² y 3x. Aunque sus coeficientes coinciden, los exponentes son distintos. Su suma queda 3x² + 3x; no se reduce a un único término.

💡 Cuando no se ve un número o no hay letras

En x el coeficiente es 1, porque x = 1·x. En −x el coeficiente es −1, porque −x = (−1)·x.

Los términos constantes, como −2 y 7, no muestran variables y pueden combinarse entre sí: −2 + 7 = 5.

Objetivos

  • Identificar términos semejantes y combinarlos correctamente.
  • Aplicar la distributiva para multiplicar expresiones.
  • Reconocer errores comunes en los signos y paréntesis.

1️⃣ Suma y resta

Solo los términos semejantes pueden reducirse a un único término sumando o restando sus coeficientes. Deben tener las mismas variables con los mismos exponentes.

También podemos sumar términos distintos: por ejemplo, 3x + 2y es una suma válida. La dejamos indicada porque sus términos no son semejantes y no se reducen a uno solo.

Ejemplo: (3x² + 5x − 2) + (4x² − 3x + 7) = 7x² + 2x + 5.

Si hay un signo “−” delante de paréntesis, cambia los signos de los términos internos antes de combinar.

Ejemplo: (6x − 3y) − (2x + 4y) = 6x − 3y − 2x − 4y = 4x − 7y.

2️⃣ Multiplicación de polinomios

Aplicamos la propiedad distributiva: cada término del primer polinomio multiplica a cada término del segundo.

Ejemplo 1: (a + b)(c + d) = ac + ad + bc + bd. Ejemplo 2: (x + 2)(x + 5) = x² + 7x + 10.

3️⃣ Multiplicación con más de dos términos

Primero se multiplican dos factores, y luego el resultado por el siguiente (usando asociativa).

Ejemplo: (x + 1)(x + 2)(x + 3) = (x² + 3x + 2)(x + 3) = x³ + 6x² + 11x + 6.

Mini-actividad · Suma, resta y producto

  1. (4x² − 3x + 7) + (−2x² + 5x − 1)
  2. (a + b)(a − b)
  3. (2x + 3)(x − 5)
  4. (x + 1)(x² + x + 1)
Mostrar soluciones
  1. (4x² − 3x + 7) + (−2x² + 5x − 1) = 2x² + 2x + 6.
  2. (a + b)(a − b) = a² − b² (diferencia de cuadrados).
  3. (2x + 3)(x − 5) = 2x² − 10x + 3x − 15 = 2x² − 7x − 15.
  4. (x + 1)(x² + x + 1) = x³ + x² + x + x² + x + 1 = x³ + 2x² + 2x + 1.
